# M2 — Rust and Go Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `whence` traces Rust and Go variables: through reassignments and mutations, past places a reference may have written them, into implementations of abstract methods, through multi-value bindings and loop variables, with every edge pointing at a syntax node the engine identified.

**Architecture:** Two new `languages/<lang>/` directories (grammar crate + `whence.scm` + `lang.toml`) and generic engine rules keyed on new captures: `@assign`, `@escape`, `@param.mutable`, `@call.receiver`, `@function.receiver[.mutable]`, `@function.abstract`, `@function.group`, `@binding.element`. One new host request, `host/implementation`, answered by both editors. The step function gains an *occurrence step* at variable uses (writes and escapes between binding and use), receivers in frames, index projections, and function identity by declaration group. No per-language Rust code.

**Tech Stack:** Rust 1.98 (edition 2024, `let` chains in use), tree-sitter 0.27, `tree-sitter-rust` 0.24, `tree-sitter-go` 0.25, existing `serde`/`anyhow`/`thiserror`; Lua (Neovim 0.11+); TypeScript (VS Code extension, `vscode-jsonrpc` 8).

**Spec:** `docs/superpowers/specs/2026-09-03-m2-rust-go-design.md` (parent `docs/superpowers/specs/2026-09-01-whence-design.md`; protocol `docs/PROTOCOL.md`).

**Tickets:** epic `whe-ooar`; tasks `whe-q0z2` (1), `whe-i4xd` (2), `whe-ue17` (3), `whe-4oen` (4), `whe-ys9i` (5), `whe-0nww` (6), `whe-j9e8` (7), `whe-aune` (8), `whe-tew1` (9). `tk ready` lists what can start; each task closes its ticket in its last step.

## Global Constraints

- No per-language Rust code: the engine reads capture names from `engine/src/lang/vocab.rs` only; grammar node names appear in `languages/*/whence.scm` and in tests, never in `engine/src` (spec parent §6, CLAUDE.md).
- Honesty rule: an edge points at a syntax node the engine identified through a capture or a host answer; several candidates are all emitted or the trace stops with `unresolved` (parent §5.5).
- Every fork passes through `candidates()` in `engine/src/trace/step.rs` so `split` and `fanout` hold everywhere (parent §5.4). The occurrence step's definition nodes are appended *after* `candidates()` and are never cut (M2 §3.1).
- Node ids and `FuncId::describe()` do not change for existing Erlang fixtures; `cargo test --test replay` must pass without `UPDATE_EXPECTED` through Tasks 1–5 and 7. If a golden changes, the task is wrong, not the golden.
- Positions on the wire are 0-based line, UTF-16 column; `whence replay` takes 1-based `line:col`.
- Fixtures are recorded with `:WhenceRecord` from real sessions (rust-analyzer, gopls), never hand-written. Nothing from `~/ringcentral` or any private codebase enters the repo: no sources, no fixture answers, no project names.
- Tests must be able to fail for a real reason: no tests of tree-sitter or the grammars themselves, no assertions on display text, no restating a fixture's contents back to itself. Contract pins on captures the engine's rules depend on are allowed (M2 §9).
- Commit messages are one line with the ticket id as `[<id>]` and must not contain the word "claude" (repo hook). Staging is allowed for this plan's work; stage exactly the files a step names.
- Never write files via shell redirection; use the file-editing tools. `cargo fmt --all` before every commit; `cargo clippy --workspace --all-targets -- -D warnings` must pass.
- `docs/DEVIATIONS.md` receives only departures from this plan, as *Plan: … Done: …*. Nothing else.

```rust
/// Start byte of the nearest `@function.group` ancestor of `f`, else of `f` itself:
/// the key that puts a function's clauses together and keeps same-name functions apart.
pub fn function_group(&self, f: &FnDecl) -> usize {
    self.nearest_ancestor_with(f.node, vocab::FUNCTION_GROUP)
        .map_or(f.node.0.start_byte(), |g| g.0.start_byte())
}

/// Every clause sharing `group`.
pub fn clauses_of(&self, group: usize) -> Vec<FnDecl<'_>> {
    self.functions()
        .into_iter()
        .filter(|c| self.function_group(c) == group)
        .collect()
}
```

```rust
/// Elements of a positional construct; `None` when it is keyed or a cons.
pub fn positional(&self, construct: N) -> Option<Vec<N<'_>>> {
    let n = self.through(construct).unwrap_or(construct);
    if !self.has_cap(n, vocab::CONSTRUCT) || self.has_cap(n, vocab::CONSTRUCT_CONS) {
        return None;
    }
    let (s, e) = (n.0.start_byte(), n.0.end_byte());
    let keyed = self
        .caps_within(vocab::CONSTRUCT_FIELD_NAME, s, e)
        .iter()
        .any(|f| f.0.parent().and_then(|x| x.parent()).map(|p| (p.start_byte(), p.end_byte())) == Some((s, e)));
    if keyed {
        return None;
    }
    Some(named_children(n).into_iter().map(|c| self.through(c).unwrap_or(c)).collect())
}

pub fn construct_element(&self, construct: N, i: usize) -> Option<N<'_>> {
    self.positional(construct)?.get(i).copied()
}

/// The identifier's position inside a positional pattern, when the pattern has several elements.
pub fn pattern_index(&self, pattern: N, ident: N) -> Option<usize> {
    let elems = self.positional(pattern)?;
    if elems.len() < 2 {
        return None;
    }
    elems.iter().position(|e| contains(e.0, ident.0))
}
```

Also make `is_literal` on a keyed construct skip the names and check the values: in the `CONSTRUCT` branch, for each named child `c`: skip if `has_cap(c, CONSTRUCT_FIELD_NAME)`; if `c` contains a `CONSTRUCT_FIELD_VALUE` child (`caps_child_of(CONSTRUCT_FIELD_VALUE, c)` non-empty) check `is_literal` of that value; else `is_literal(c)`.

```rust
    pub target: N<'t>,
    pub value: Option<N<'t>>,

impl Doc<'_> {
    /// The `@assign` whose target contains `occ`, if any.
    pub fn assign_at(&self, occ: N) -> Option<Assign<'_>> {
        let target = self.nearest_ancestor_with_or_self(occ, vocab::ASSIGN_TARGET)?;
        let node = target.0.parent().map(N)?;
        if !self.has_cap(node, vocab::ASSIGN) { return None; }
        let node = self.node(Span::of(node))?;
        Some(Assign {
            node,
            target: self.node(Span::of(target))?,
            value: self.caps_child_of(vocab::ASSIGN_VALUE, node).first().copied(),
            compound: self.has_cap(node, vocab::ASSIGN_COMPOUND),
        })
    }

    pub fn escaped(&self, occ: N) -> Option<N<'_>> {
        self.nearest_ancestor_with_or_self(occ, vocab::ESCAPE)

    /// The innermost call that passes `occ` as its receiver or as argument `i`.
    pub fn call_using(&self, occ: N) -> Option<(CallSite<'_>, Slot)> {
        let call = self.nearest_ancestor_with(occ, vocab::CALL)?;

        if call.receiver.is_some_and(|r| contains(r.0, occ.0)) {
            return Some((call, Slot::Receiver));

        let i = call.args.iter().position(|a| contains(a.0, occ.0))?;
        Some((call, Slot::Arg(i)))

}
```

3. `doc.escaped(o)` → `Occ::Escape(o, format!("may be written by {}", first_line_of(doc, escape_node_parent_statement)))`. Use the text of the nearest `@call` ancestor when there is one, else the `@escape` node's line.

5. Else drop.
